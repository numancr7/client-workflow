Trigger Logic

Decision flow for each automated message

Welcome Message Trigger

◆Retention Agreement Signed? → YES → ◆Days Since Retention = 0? → YES → ✓ SEND Welcome Message

Insurance Follow-up Trigger

◆Days Since Retention = 7? → YES → ◆Insurance Info Received = NO? → YES → ✓ SEND Insurance Request

Police Report Follow-up Trigger

◆Days Since Retention = 14? → YES → ◆Police Report Received = NO? → YES → ✓ SEND Police Report Request

Status Update Trigger

◆Days Since Retention ≥ 14? → YES → ◆Last Update > 14 Days Ago? → YES → ◆Case NOT Closed/Settled? → YES → ✓ SEND Status Update

Missing Document Reminder Trigger

◆Days Since Retention ≥ 10? → YES → ◆Any Documents Missing? → YES → ◆Last Reminder > 7 Days? → YES → ✓ SEND Missing Doc Reminder

Escalation Additional Rules

⚡

Authorization Escalation

If: Day 21+ AND authorizations missing AND 2+ reminders sent

Then: Escalate to paralegal for a phone call

🚨

Medical Records Final Push

If: Day 30+ AND medical records missing

Then: Flag for attorney review, contact provider directly

📥 INPUT — Raw Case Notes
"Client rear-ended on I-95, 3/15/26. Soft tissue injury, ongoing PT 2x/week. Insurance adjuster assigned, no offer yet. Police report received 3/28. Awaiting final medical records from PT clinic. Client anxious about timeline, called twice this week."
📤 OUTPUT — Professional Summary
The client was involved in a rear-end motor vehicle collision on I-95 on March 15, 2026, sustaining soft tissue injuries requiring ongoing physical therapy twice per week. The police report was obtained on March 28, 2026, and an insurance adjuster has been assigned, though no settlement offer has been extended. We are awaiting final medical records from the treating PT clinic. The client has expressed concern about the timeline and has contacted the office twice this week — a courtesy call is recommended within 24 hours to manage expectations.
